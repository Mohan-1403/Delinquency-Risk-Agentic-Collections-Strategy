## 📌 Executive Summary
This project outlines an end-to-end credit risk assessment and autonomous collections strategy conducted for **Geldium** in partnership with **Tata iQ**[cite: 2, 11]. It addresses non-linear default behaviors across a 500-customer credit portfolio. 

The project delivers:
1. **Exploratory Data Analysis (EDA):** Complete audit of missingness mechanisms (MCAR/MAR), categorical fragmentation, and credit limit breaches.
2. **Predictive Modeling Framework:** Conceptual design of a **Gradient Boosted Decision Tree (LightGBM/XGBoost)** pipeline optimized for severe class imbalance (16% default rate) using **AUC-ROC** and **Recall**[cite: 1, 4].
3. **Responsible AI & Explainability:** Integration of **SHAP (Shapley Additive Explanations)** and algorithmic fairness audits (Disparate Impact & Demographic Parity)[cite: 1, 4].
4. **Agentic Collections Blueprint:** A closed-loop AI strategy featuring automated early interventions, projected to reduce 90-day roll rates by 25% while maintaining human-in-the-loop oversight on legal and hardship escalations.
